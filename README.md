# In-TAKO

The In-TAKO member app for Android, from In-TAKO Refilling Station in Bontoc,
Mountain Province. Earn Green Points, see your refill history and receipts,
choose rewards, and order refills ahead.

## Download

**[Download In-TAKO for Android](https://github.com/Shadrack0747/In-TAKO-App/releases/latest/download/In-TAKO.apk)**
(Android 7.0 or later)

file manager. Google Play: coming soon.
